1. 빠른 시작 — 처음 쓰는 분은 이 순서대로

1
TRIOS에서 데이터 내보내기
측정 파일을 열고 Export → Text(.txt)로 저장합니다. 파일 이름은 아래 파일명 규칙대로 지어 주세요 (예: 261117 APIM 10-1 K4 60R 18C #1.txt). 같은 로트를 여러 번 측정했다면 … (1).txt, … (2).txt처럼 끝에 번호를 붙이면 자동으로 한 로트로 묶입니다.
2
Blank(빈 팬) 파일 먼저 올리기 (권장)
시료 없이 빈 팬만 같은 조건으로 측정한 파일 이름에 BLANK를 넣어 올리면, 이후 모든 시료에서 자동으로 차감됩니다. 장비 바탕 신호가 빠져 결과가 정확해집니다.
3
[데이터 분석] 탭에 시료 파일 끌어다 놓기
여러 개를 한 번에 올려도 됩니다. 업로드와 동시에 계산되고 자동 저장됩니다. 공정(Mixing/Kneading)은 파일명으로 자동 판별되며, 로트 카드의 드롭다운에서 바꿀 수 있습니다.
4
PTFE 함량과 질량 확인
로트 카드의 PTFE (wt%) 값이 실제 배합과 맞는지 확인하세요. 질량(mg)은 파일에서 자동으로 읽지만, 비어 있으면 빨갛게 표시되니 직접 입력하세요.
5
[그래프] 버튼으로 적분 구간 확인
파란 영역이 피크 전체를 덮고 있으면 정상입니다. 어긋나 있으면 그래프의 파란 세로선을 마우스로 끌어 옮기거나 숫자를 입력하세요. 상태가 정상이 아니면 이유를 확인하세요.
6
[대시보드]에서 비교
왼쪽 목록에서 비교할 로트/샘플을 체크하면 결정화도 막대그래프(오차막대 포함)와 표가 나옵니다. 그래프는 이미지 복사 후 PPT에 바로 붙여넣을 수 있고, 표는 표 복사로 엑셀에 붙여넣을 수 있습니다.
처음이라면 [데이터 분석] 탭의 예제 데이터 버튼으로 가상 데이터를 불러와 연습해 보세요. 다시 누르면 예제만 삭제됩니다.

2. 파일명 규칙

공정형식예시
Mixing (믹싱)yymmdd APIM 10-1 [#배치] [기타]261117 APIM 10-1 #2 증속평가 (1).txt
Kneading (니딩)yymmdd APIM 10-1 K4 60R 18C [#배치] [기타]261117 APIM 10-1 K6 95R 18C #1 30Hz.txt
항목의미
yymmdd연월일 (261117 → 2026-11-17). 대시보드 날짜 필터에 사용
APIMA=Anode(고정), P=Pilot(고정), I=변경 코드 (레시피·공정조건·소재 변경 시 알파벳이 바뀜), M=Mixing(고정)
10-1앞 숫자 10 = 1000 kg (고정), 뒤 숫자 = 같은 레시피 안에서 공정 변수 번호
K4투입량 (4 → 400 kg/hr). 이 항목이 있으면 Kneading으로 자동 판별
60R니딩 RPM (60 rpm)
18C설정온도 (18 → 180 °C)
#1배치 번호 (Mixing은 10-1 뒤, Kneading은 18C 뒤)
기타 문자증속평가, 50Hz 등 — 로트 이름의 일부로 보존되어 서로 다른 로트로 구분됨
(1), (2)맨 끝의 괄호 번호 = 같은 로트의 반복 측정 시료. 괄호 없는 원본 = 시료 1, (1) = 시료 2 …
파일명 해석 테스트 — 파일명을 입력하면 프로그램이 어떻게 읽는지 바로 보여줍니다.

3. 화면별 사용법

데이터 분석

  • 로트 카드: 같은 로트의 시료가 한 카드에 묶이고, 오른쪽 위에 결정화도 평균 ± 표준편차(SD)가 표시됩니다.
  • 공정 / PTFE / 메모: 로트 단위로 바꾸면 그 로트의 모든 시료에 적용됩니다. 특정 시료만 PTFE 함량이 다르면 표의 PTFE 칸에 직접 입력하세요 (노란색 = 개별 설정).
  • 포함 체크박스: 해제하면 그 시료는 평균·SD·대시보드 계산에서 빠집니다 (측정 오류 시료 제외용). 데이터는 남아 있습니다.
  • 적분구간 칸: 숫자를 바꾸면 그 시료만 다시 계산됩니다 (노란색 = SOP와 다른 수동 값, ↺ 버튼으로 되돌리기).
  • 삭제: 시료 삭제는 바로 실행되며 알림창의 되돌리기로 복구할 수 있습니다. 로트 삭제는 확인 후 실행됩니다.
  • 곡선 겹쳐보기: 로트 안 시료들의 곡선을 한 그래프에 겹쳐 재현성을 확인합니다.
  • 샘플 목록 보기: 위쪽 보기 방식을 바꾸면 모든 시료를 한 표로 볼 수 있습니다.

그래프 창 (시료별 상세)

  • ① Heat Flow: 파란 실선 = Blank 차감·질량 정규화 후 곡선, 회색 = 스무딩 전, 빨간 점선 = 베이스라인, 파란 영역 = 적분 면적.
  • ② 미분 곡선: 곡선의 기울기. 피크 시작 전후가 0 근처로 평탄해야 좋은 적분 구간입니다.
  • 파란 세로선(시작/종료)을 마우스로 끌면 구간이 바뀌고 즉시 재계산·저장됩니다. 로트 전체에 적용으로 같은 구간을 그 로트의 모든 시료에 줄 수 있습니다.
  • 키보드 ← → 로 이전/다음 시료, Esc로 닫기.

대시보드

  • 검색: 띄어쓰기로 여러 단어를 넣으면 모두 포함된 로트만 표시 (예: K4 18C).
  • 선택: 로트 체크 = 그 로트의 모든 시료, ▾를 눌러 개별 시료만 골라 비교할 수도 있습니다.
  • 비교 단위: 로트별은 평균 막대 + 오차막대 + 개별 점, 샘플별은 시료 하나하나를 막대로 보여줍니다.
  • 묶음 기준 = 조건: #1, #2 배치를 하나의 조건으로 합쳐 평균을 냅니다.
  • 기준 로트: 선택하면 표에 기준 대비 차이(Δ)가 나오고, 그래프에 기준선이 그려집니다.
  • 모든 그래프 오른쪽 위: 이미지 복사(클립보드) · PNG 저장 · SVG 저장(고해상도 보고서용).

4. 분석 원리

DSC는 시료를 일정 속도로 가열하며 드나드는 열량을 측정합니다. PTFE 결정은 약 327 °C 부근에서 녹으며 열을 흡수(흡열 피크)하는데, 이 피크 면적이 결정이 녹는 데 필요한 에너지(융해 엔탈피 ΔHm)입니다. 결정이 많을수록 면적이 커집니다.

  1. 데이터 읽기: Temperature / Heat Flow / Time 열을 자동으로 찾고, 가열 구간(1st Heating 등)만 골라 0.2 °C 간격으로 정리합니다.
  2. Blank 차감 & 질량 정규화: 빈 팬 신호를 빼고 시료 질량으로 나눠 W/g 단위로 만듭니다.
    HF(T) = [ HF시료(T) − HFBlank(T) ] / m시료   [mW/mg = W/g]
  3. 스무딩 & 미분: Savitzky-Golay 필터(기본 15점, 3차)로 노이즈를 줄이고 1차 미분(dHF/dT)을 계산합니다.
  4. 베이스라인: 적분 시작·종료 온도의 곡선 값을 직선으로 이은 선입니다.
  5. 면적 → 엔탈피: 곡선과 베이스라인 사이 면적(W/g·°C)을 승온 속도로 나눠 J/g로 바꿉니다.
    ΔHm (J/g) = (60 / β) × ∫T₁T₂ | HF(T) − BL(T) | dT
    β = 승온 속도(°C/min). 60은 분→초 환산. Time 열이 있으면 실제 데이터에서 β를 계산합니다.
  6. 결정화도: 측정한 시료(전극) 1 g 안에 PTFE는 w(=wt%/100)만큼만 들어 있으므로 함량으로 보정합니다.
    Xc (%) = ΔHm / ( ΔH°m × wPTFE ) × 100
    예) ΔHm = 0.45 J/g, PTFE 1 wt%, ΔH°m = 82 J/g → 0.45 / (82 × 0.01) × 100 = 54.9 %
  7. 피크 / Onset 온도: 피크 = 베이스라인에서 가장 멀리 떨어진 점. Onset = 피크 앞쪽에서 기울기가 가장 큰 점의 접선이 베이스라인과 만나는 온도 (접선 외삽법). Endset도 같은 방식으로 피크 뒤쪽에서 구합니다.

5. 상태 표시 의미

정상문제 없이 계산됨
참고계산은 정상이지만 알아둘 내용 (예: Blank 미적용, 실제 승온 속도가 SOP와 다름)
확인 필요결과가 틀렸을 수 있음 — 피크가 적분 경계에 붙음, 베이스라인이 곡선을 가로지름, 결정화도 100% 초과 등. 그래프를 열어 구간을 확인하세요.
오류계산 불가 — 질량 없음, 데이터가 적분 구간을 포함하지 않음, 흡열 피크 없음 등. 오류 시료는 평균에서 자동 제외됩니다.

상태 배지에 마우스를 올리면 구체적인 이유가 나옵니다.

6. 자주 묻는 질문 / 문제 해결

  • 결정화도가 100%를 넘거나 너무 낮아요. → PTFE 함량(wt%)이 실제 배합과 같은지, 질량(mg)이 맞는지, Blank가 같은 조건(팬 종류·승온 속도)으로 측정된 것인지 확인하세요.
  • “열 머리글을 찾지 못했습니다” 오류 → TRIOS에서 내보낼 때 Temperature와 Heat Flow 신호가 포함되도록 하세요. 파일 안에 이 두 단어가 있는 줄이 있어야 합니다.
  • 엑셀(.xlsx) 파일이 안 올라가요. → 엑셀 해석 기능은 처음 사용할 때 인터넷에서 라이브러리를 받습니다. 사내망에서 막혀 있으면 .txt 또는 .csv로 내보내 주세요.
  • 같은 파일을 다시 올리면? → 같은 파일명은 새 데이터로 교체되며, 포함 여부·수동 구간 등 설정은 유지됩니다.
  • 데이터는 어디에 저장되나요? → 이 PC 브라우저 내부 저장소입니다. 서버로 전송되지 않습니다. 다른 사람과 공유하거나 PC를 바꿀 때는 SOP 설정 탭의 백업 파일 저장/불러오기를 쓰세요.
  • SOP 값을 바꿨는데 일부 시료가 그대로예요. → 시료별로 직접 바꾼 적분 구간(노란색)은 유지됩니다. 저장할 때 “직접 바꾼 적분 구간도 초기화”를 체크하세요.
  • 그래프 이미지 복사가 안 돼요. → 일부 브라우저는 클립보드 이미지 복사를 막습니다. Chrome/Edge 사용을 권장하며, 안 되면 PNG 저장을 쓰세요.

7. v6.13 대비 변경점

  • 저장소를 localStorage(약 5 MB 한도)에서 IndexedDB로 바꿔 대량 데이터도 자동 저장. 백업/복원 추가. v6 데이터 가져오기 지원.
  • 정규화 Heat Flow(W/g) 파일의 단위 변환 오류(1000배) 수정. W, mW, W/g, mW/g 단위 자동 인식.
  • 가열-냉각-가열 파일에서 승온 구간만 골라 분석 (1st / 2nd Heating 선택).
  • Savitzky-Golay 스무딩, 접선법 Onset/Endset, 흡열 방향 자동 판별, 승온 속도 자동 계산 추가. 적분은 절댓값 누적 대신 부호를 고려한 면적으로 계산해 노이즈 영향 감소.
  • 파일명 규칙(변경코드, 레시피, 투입량, RPM, 설정온도, 배치) 자동 해석 → 대시보드 필터·조건별 그래프에 활용.
  • 그래프 복사/저장이 모든 그래프에서 동작 (기존: 색상이 빠지던 문제 수정), 그래프에서 적분 구간 드래그 조정.
  • 대시보드: 샘플 단위 선택, 오차막대 종류 선택(SD/SE/범위), 개별 점 표시, 기준 로트 대비 Δ, 조건 vs Xc 그래프, 곡선 겹쳐보기, 표 복사/CSV.
  • 기존 SME(토크·RPM 입력) 항목은 파일명에 토크 정보가 없어 제외했습니다.

② 1차 미분 곡선 (dHF/dT)
