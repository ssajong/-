# DSC PTFE 결정화도 분석기 (v7.0)

건식전극 내 PTFE 바인더의 DSC 용융 피크로부터 **결정화도 Xc (%)** 를 자동 계산하는 단일 HTML 프로그램입니다.
설치 없이 `DSC_PTFE_Analyzer.html` 파일을 Chrome / Edge로 열면 바로 사용할 수 있습니다 (인터넷 불필요, .xlsx 업로드만 예외).

## 탭 구성
| 탭 | 내용 |
|---|---|
| 데이터 분석 | Raw 파일 업로드(자동 저장), Blank 관리, 로트별 카드 / 샘플 목록, 공정·PTFE·질량·적분구간 수정, 개별·로트 삭제(되돌리기), 시료별 상세 그래프 |
| 대시보드 | 검색·공정·날짜 필터, 로트/샘플 체크박스 선택 비교, 평균 ± SD/SE/범위 오차막대, 기준 로트 대비 Δ, 조건 vs Xc, 곡선 겹쳐보기, 결과 표 복사/CSV |
| SOP 설정 | Mixing/Kneading 적분 구간·그래프(미분) 구간·기본 PTFE 함량, ΔH°m, 승온 속도, 스무딩, 파일명 해석 배수, 백업/복원 |
| 분석 원리/사용법 | 비전문가용 단계별 사용법, 파일명 규칙 + 해석 테스트, 계산식, 상태 표시 의미, FAQ |

## 계산식
- 순수 Heat Flow: `HF = (HF_sample − HF_blank) / m_sample` [W/g]
- 융해 엔탈피: `ΔHm = (60/β) × ∫(HF − Baseline) dT` [J/g], 직선 베이스라인, β = 승온 속도(°C/min, Time 열에서 자동 계산)
- 결정화도: `Xc(%) = ΔHm / (ΔH°m × w_PTFE) × 100`
